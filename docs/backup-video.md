# Backup demo video (2 minutes)

Record this once the day before. If anything fails on stage, play it and keep talking.

## How to record on Windows

1. Press **Win + Alt + R** to start and stop recording (Xbox Game Bar records the current window), or use **OBS Studio** (free) for the full screen plus microphone.
2. Put the stage in Chrome full screen (**F11**) on the main monitor, with the chaos panel on a second screen or a phone.
3. Use a headset mic and record your voice live; it's more natural than adding it afterwards.
4. Resolution 1920×1080, 30 fps. Keep the file under 100 MB so it uploads anywhere.
